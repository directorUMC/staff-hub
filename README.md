# UMC Staff Hub page

Holder page for the UMC Staff Hub at https://hub.uprightmigration.com.au/ (GitHub Pages).
It shows the Hub's Google Apps Script web app inside a "credentialless" frame, the same way
https://calls.uprightmigration.com.au/ shows the Call Back Sheet, so Chrome with several Google
accounts never gets "Sorry, unable to open the file". Google and Dropbox sign-in come back to this page.

No secrets and no client data live here. The Hub's code is in directorUMC/umc-automation (staff-hub-gas/).
